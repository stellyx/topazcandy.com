# topazcandy.com

Topaz Candy's public website, service directory and a growing demonstration template library. Information requests use the automatic website form in `contact/`; the shared fixed-price website cart is in `checkout/`. Broader services are presented before checkout. See those directories' READMEs for delivery, package scope and verification limits.

Run `node scripts/check-contact.mjs` and `node scripts/check-purchase.mjs` from the repository root. The retained hair source and generated output are in `templates/hair-stylist/`; the owner-private carpet preview is synchronized separately with its existing audience.


The bilingual beginner course extension is in `30-day-ai/`, with a Spanish route at `/30-day-ai/es/`. See `30-day-ai/README.md` for enrollment, content updates and publication checks.

Head Shop is the complete storefront at /showcase/lab/form/: glass and accessory collections, product/color details, a bounded demo bag, shopping-list download, FAQs, a local-only message preview, and the preserved live glass configurator with its beach/grab/smoke loops. The homepage opens it directly; the shared $450 website purchase controls use /checkout/?template=form. Sample product orders are not enabled. Inventory, physical glass and ordering integrations are separate.

Portfolio identities sit inside each film or art preview and use the respective demo lettering. Desktop shows three columns from 1120px, with direct repair, website and service paths. SHIRO and Signal use optimized Runway loops in the portfolio and their hosted demos; Head Shop reuses the existing beach film, and InkMaster Pedro reuses the approved living moth. Preview films stay at 85% opacity with no tint, and pause off-screen, in hidden tabs and under motion/data preferences.
