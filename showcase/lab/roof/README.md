# UPPERHAND roofing motion

The fictional roofing concept uses a local 9.42-second, silent, two-scene loop: shingle placement, then rain across a finished roof. The failed nailer scene from the 15-second source was excluded for visible tool/contact errors. This is illustrative film, not customer-work evidence or an installation guide.

- `roofing-loop.mp4`: 960 × 540 H.264, 24 fps, 641,867 bytes, faststart.
- `roofing-poster.webp`: local still fallback from the retained placement shot.
- `motion.js`: opt-in for reduced motion/data saving, explicit pause preserved, suspension off screen or in a hidden tab, graceful poster fallback.
- `motion.css`: site-matched charcoal/oxide treatment; film above the headline on narrow layouts; usable 44px toggle.
- `motion-generation.json`: source task, exact retained ranges, hashes, and rejection reason. The original is preserved independently; the website has no dependency on expiring generation URLs.

Validation before deployment: syntax check, HTML/assets/anchors/noindex checks, media metadata, and regression checks for autoplay, manual pause, viewport/tab suspension, preference opt-in, blocked playback, and error fallback. Live browser checks follow deployment.

Keep all changes in `showcase/lab/roof/`. The concept planner remains browser-local and does not send inquiries, book work, or collect payments.
