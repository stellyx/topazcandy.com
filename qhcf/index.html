Using routes

Every literal + crossed on a map counts as one step. An authorized play agent should identify the current room from actual output, announce the destination and computed directional counts followed by "I am performing that now," then execute short verified movement segments. It must stop immediately if the user takes over, re-localize on unexpected movement, and confirm arrival from actual game output. Do not invent connections across walls, blank space, ambiguous crossings, diagonals, vertical transitions, or special exits.
